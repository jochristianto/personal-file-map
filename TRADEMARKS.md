# Name and logo policy

The source code of Bills Overview is available under the [PolyForm Noncommercial License 1.0.0](LICENSE). That license covers the **code** only. It does not give anyone rights to the project's **name** ("Bills Overview") or its **app icon** (the receipt with the green check). This page explains what you can and can't do with them.

## In short

| You want to… | OK? |
|---|---|
| Use the app yourself, at home, for free | ✅ Yes |
| Fork the repo, change it, build it for yourself | ✅ Yes |
| Say your project is "based on Bills Overview" or "a fork of Bills Overview", with a link back | ✅ Yes |
| Write about, review or teach with Bills Overview | ✅ Yes |
| Share a modified, free, noncommercial build **under a different name and icon** | ✅ Yes, with the license and its `Required Notice` line included |
| Share a modified build under the name "Bills Overview" or with its icon | ❌ No, people would think it's the original |
| Sell the app, or a modified version, **under any name** | ❌ No, the license forbids commercial use |
| Offer it as part of a paid product or service, or bundle it with one, **under any name** | ❌ No, the license forbids commercial use |
| Use a confusingly similar name or icon (e.g. "Bill Overview Pro") | ❌ No |

## Why

Two separate rules work together:

1. **The license** ([PolyForm Noncommercial 1.0.0](LICENSE)) allows only noncommercial use. Selling the app, charging for it, or using it to make money is not allowed, whether it's called Bills Overview or something else. Renaming a copy doesn't change what it is.
2. **This policy** keeps the name and icon pointing at one project, so that people who download "Bills Overview" get this project and know whom to ask for help.

## Commercial use

If you'd like to use Bills Overview commercially (in a business, in a paid product, or as a service), open an issue asking how to get in touch about a separate commercial license. Nothing on this page or in the license grants one.

## Reporting misuse

If you find the app being sold, or the name or icon used in a misleading way, please open an issue with a link.
